# 💈 Interface — Barbearia do Gegeu

Projeto desenvolvido na disciplina de **Interface Homem-Computador (IHC)** durante o curso Técnico em Desenvolvimento de Sistemas do SENAI.

## 📌 Sobre o projeto

A proposta foi desenvolver uma interface web para uma barbearia, trabalhando aspectos de organização visual, apresentação de informações e experiência do usuário.

A página apresenta a história da barbearia, seus serviços, uma galeria de trabalhos e um vídeo do espaço.

## 🎨 Interface

O projeto utiliza elementos visuais para criar uma identidade própria para a barbearia, incluindo:

- Organização das informações por seções
- Identidade visual
- Tipografia personalizada
- Galeria de imagens
- Apresentação de serviços
- Elementos de interação
- Animações e efeitos visuais

- CSS3
